# Machine Learning Beginner Projects 🚀

This repository contains four practical Machine Learning projects implemented using Python and `scikit-learn`. These projects demonstrate fundamental supervised learning algorithms, including Linear Regression, Naive Bayes, Decision Trees, and Classification.

---

## 📌 Projects Included

### 1. Student Marks Prediction (`student_marks_prediction.py`)
* **Algorithm:** Linear Regression
* **Objective:** Predicts exam scores based on hours studied.
* **Key Concept:** Simple Supervised Regression.

### 2. Email Spam Filter (`email_spam_filter.py`)
* **Algorithm:** Multinomial Naive Bayes
* **Objective:** Classifies incoming text messages as `SPAM` or `NOT SPAM`.
* **Key Concept:** Text Vectorization (`CountVectorizer`) and Natural Language Processing basics.

### 3. Iris Flower Classification (`iris_flower_classification.py`)
* **Algorithm:** Decision Tree Classifier
* **Objective:** Predicts flower species based on physical feature measurements.
* **Key Concept:** Multi-class classification and dataset splitting (`train_test_split`).

### 4. House Price Estimator (`house_price_estimator.py`)
* **Algorithm:** Multiple Linear Regression
* **Objective:** Estimates property pricing based on square footage and bedroom count.
* **Key Concept:** Regression with multiple features.
